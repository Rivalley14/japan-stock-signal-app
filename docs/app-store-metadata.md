## 説明文（4000文字以内）

```
「日本株シグナル（経験者用）」は、日本株の個別銘柄分析とトレンド検出を行うテクニカル・ファンダメンタル分析アプリです。

■ 主な機能

・銘柄検索
日本株の銘柄名またはコードで検索し、株価チャートとテクニカル指標をすぐに確認できます。

・トレンド分析（クロス・スクリーニング）
主要銘柄を対象に、移動平均のゴールデンクロス/デッドクロス、MACD、ボリンジャーバンドのブレイクを自動検出し、一覧で確認できます。バックグラウンドで定期的に自動更新されます。

・テクニカル指標
SMA（単純移動平均）、RSI、MACD、ボリンジャーバンド、ストキャスティクス、OBV、VWAPなど主要な指標を1画面で確認できます。

・ファンダメンタル指標
PER、PBR、ROE、ROA、EPS、配当利回り、時価総額、営業利益率など主要な財務指標を表示します。

・総合シグナル
テクニカルとファンダメンタルの指標をルールベースで評価し、5段階の目安を表示します。根拠となった指標も併せて確認できます。

・ウォッチリスト
気になる銘柄を登録し、現在値と前日比をいつでも確認できます。データは端末内に保存されます。

■ ご利用にあたって

本アプリが表示する分析結果・シグナルは、あらかじめ登録されたルールに基づく機械的な目安であり、投資助言ではありません。投資に関する最終判断は、必ずご自身の責任で行ってください。

本アプリは無料でご利用いただけます。広告表示による収益で運営しています。
```

## App Privacy（データ収集の申告）

App Store Connectの「App Privacy」セクションで、以下の内容を申告してください（AdMobを利用する場合の一般的な申告例。実際の設定はAdMob管理画面の指示に従ってください）。

- **識別子（Identifier）** → 広告に使用（Device ID等） → ユーザーにリンクなし/リンクあり（AdMobの設定に依存）
- **使用状況データ（Usage Data）** → 広告に使用
- 収集していない項目（連絡先、位置情報、健康情報、写真等）は「収集なし」を選択

## 審査時の注意点（Apple Review Guidelines関連）

- 金融情報アプリのため、投資助言でない旨の免責文言を各シグナル表示箇所に明記済み（審査担当者から確認される場合あり）
- AdMobの広告ユニットIDは実際に発行したものに差し替え済み（`ca-app-pub-5270276427916354/...`）。ただしAdMob側のアプリ審査が完了するまでは広告が空欄/no fillになる場合がある旨、必要であればレビュー担当者向けメモに記載
- レビュー用の説明（App Review Information）に、バックエンドサーバーが必要な構成である旨と、テスト用にログイン不要ですぐ使える旨を記載すると審査がスムーズです
